局域网

三台都要监听局域网，不能只绑 127.0.0.1。页面端口和同步端口在上面自行设定；默认是 0.0.0.0:8765 和 UDP/TCP 8766，请在防火墙放行这两个端口。列表只显示同一资产版本的机器。程序更新仍走 GitHub：本机 push 并合并后，其他机器 git pull 再重启。没开 QuantLab 的机器不会出现。回测产物互相补缺（已有目录不覆盖，_deleted/ 合并）；行情只同步 data/。不要用 git 同步 data/、quantlab_runtime/results/、db/、config/。A 股实例不要和数字货币实例互相点同步。
