资产版本与端口

本实例标明面向哪一类资产。A 股和数字货币请用两套目录、两套端口，局域网只发现同一资产。页面端口和同步端口可自行设定；保存后写入 quantlab_runtime/config/instance.json，需重启 QuantLab 才切换监听。

局域网

三台都要监听局域网，不能只绑 127.0.0.1。页面端口和同步端口在上面自行设定；默认是 0.0.0.0:8765 和 UDP/TCP 8766，请在防火墙放行这两个端口。列表只显示同一资产版本的机器。程序更新仍走 GitHub：本机 push 并合并后，其他机器 git pull 再重启。没开 QuantLab 的机器不会出现。回测产物互相补缺（已有目录不覆盖，_deleted/ 合并）。数据同步先对文件大小和修改时间，对端已有且相同的不下载；只推下面勾选的类别，不同步因子库 SQLite 和 quantlab_runtime/factors/。不要用 git 同步 data/、quantlab_runtime/results/、db/、config/。A 股实例不要和数字货币实例互相点同步。
