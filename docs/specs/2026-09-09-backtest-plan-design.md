# 回测计划

日期：2026-09-09  
状态：已确认

## 目标

在回测中心提供一份可勾选的回测任务清单。配置先写入计划、不自动开跑。用户全选后点开始，系统按勾选顺序一笔接一笔执行；前一笔完成或失败后再跑下一笔。写计划的人填完即可离开。

## 决策

- 串行：同一时刻只跑一笔回测。16GB 机器上禁止计划内并行。
- 一笔失败不中止整份计划，继续下一笔。
- 停止计划：停当前运算，未跑的仍保持待运行，可再次勾选开始。
- 已完成的条目默认不再重跑。
- 计划运行期间，工作台「开始回测」也拒绝新开，避免两路运算叠在一起。
- 不改训练方式、成交语义、因子公式。

## 界面

- 侧栏：回测中心下增加「回测计划」。
- 计划页：复选框、全选、开始、停止计划。每行显示名称、因子、训练/回测区间、模型、状态、运行记录链接。
- 工作台「回测计划」下拉为选填：保存配置和开始回测都不依赖它。只有点「加入计划」时才需要选中一份未完结计划。
- 计划页「新建计划」：弹窗填写名称，系统生成 `plan_id` 主键。
- 计划可「完结」：完结后不能再改任务或开跑，也不出现在工作台下拉框。
- 计划可「删除」：仅当计划中没有任何任务时允许删除（含已完结的空计划）。
- 计划任务可全选后「删除任务」：删掉勾选的条目。完结或运行中的计划不能改任务。

## 不做

- 计划内并行。
- 失败即停整份计划。
- 把 22/29 个因子默认塞进同一条任务。
