# 局域网发现与文件同步

日期：2026-09-10

## 决定

浏览器仍只绑 `127.0.0.1:8765`。另开局域网端口 `8766`（HTTP + UDP 宣告），只给 QuantLab 互相同步文件，不开 SQLite、不提供页面、不提供 Token。

设置页「局域网」列出正在开着 QuantLab 的机器（UDP 宣告，约 15 秒内收到过）。没开服务的机器不出现。

不同步 `quantlab_runtime/db/`、`config/`。

## 回测产物

点「同步回测产物」：在线机器互相拉，多轮直到不再缺。

- 本机没有的 `results/<run_id>/` 从对端整目录补来。
- 本机已有的目录不覆盖。
- `_deleted/` 合并：对端有、本机没有的标记拷过来。
- 结束后走现有 `sync_result_catalog`（补机器码、按标记删除、扫 `run.json`）。

最多 8 轮，避免死循环。

## 行情

与产物分开，只同步 `data/`（相对 `data_root` 的文件）。源头机器的文件覆盖对端同路径且内容不同的文件；对端多出来的文件不删。

点列表里某台 = 那台当源头，其他在线机器（含本机，若本机不是源头）从它拉行情。

「每天 04:00 自动同步行情」开着且服务在跑：到点后**本机当源头**，推给当时在线的其他机器。错过 04:00 不补跑。也可手动点「开始同步行情」（源头=本机）。

## 明确不做

- 把页面服务绑到 `0.0.0.0`
- 同步库、Token、机器码、运算设置
- 镜像删除整个 `data/` 或 `results/`
- 因子/模型目录的完整同步（本阶段）
