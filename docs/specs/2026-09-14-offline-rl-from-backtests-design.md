# 最简离线强化学习：按日选择专家策略

日期：2026-09-14  
状态：已实现（计划 docs/plans/2026-09-14-offline-rl-expert-q.md；页面 /backtests/offline-rl）  
取代：同日模仿蒸馏稿，以及本文件此前「池内连续权重 + IQL/TD3+BC」的第一期表述。

## 目标

另做一套方法，和回测中心无关：不把未来收益当分档标签，也不用 LightGBM 给股票打分。从已有自然年回测抽出轨迹，用**最简单的离线强化学习**学一件事——**今天跟哪一条已经跑过的专家策略**。奖励是当日组合相对沪深300的超额。

成功标准：样本外自然年，学到的策略平均夏普必须高于**重放对照**（上年成绩最好的固定专家在该年的表现），且平均超额不更差。打不赢即失败，不替换现有回测中心。

## 为什么这是「最简单的 RL」

回测中心的模式是：股票×日 → 标签=未来收益 → 排序树。那是监督学习。

本方法的决策单位是**整段组合**，不是个股分数：

| | 回测中心 | 本方法（第一期） |
|---|---|---|
| 谁在决策 | 每天给每只股票打分 | 每天在 K 个专家里选一个 |
| 标签/奖励 | 未来收益分档（监督） | 当日组合超额（强化学习） |
| 动作个数 | 与股票数成正比 | 固定 K 个（默认 8） |
| 算法 | LightGBM Ranker | 离散动作 Q 学习（Fitted Q） |

第一期不学个股权重、不上 PPO、不上 IQL。权重和 Top N 全部沿用被选中的那条专家自己的规则（通常已是等权 Top4）。

## 马尔可夫决策过程

**动作 a_t（离散）**  
从当年允许的专家集合里选一个配置指纹（因子+过滤+Top N+加权+开仓规则）。执行结果 = 该专家当天在档案里已经持有的股票、等权（或缺席则按同一规则用当日截面重算持仓）。允许「保持现金」作为第 0 号动作。

专家集合：测试区间落在单一自然年、同指纹跨年可对齐的配置。长窗排除。默认每年用 **Y 年之前夏普最高的 K 条** 作为可选动作（K=8），训练与评估用同一套规则生成动作表，但 **Y 年评估不得用 Y 年夏普来挑这 K 条**，只许用 Y 之前。

**状态 s_t（小向量，不是全市场因子矩阵）**  
只用决策需要的市场与专家摘要，例如：沪深300相对均线、近 20 日波动、各专家近 20 日超额、当前持仓对应的专家编号、现金比例。不含个股未来收益，不含当年未结束的夏普。

**奖励 r_t**  
当日所选专家组合收益 − 沪深300当日收益。费用按该条回测已计入的曲线还原；若某日该专家没有持仓记录，该日该动作视为不可用（Q 值不更新为可执行）。

**转移**  
离线：下一状态来自历史。训练不与市场互动。评估年 Y 把学到的策略（每天选出的专家）按日拼接持仓，用现有账户口径汇总曲线，与重放对比。

## 算法（第一期钉死）

**Fitted Q-iteration（离散 Q）**，动作数 = K+1。

- 从轨迹建 `(s, a, r, s')`：a 是该日这条回测对应的专家编号。
- 用表格或极浅模型拟合 Q(s,a)（优先小 MLP 或线性，不用排序树）。
- 行为几乎总是「整天跟同一个专家」，所以数据里切换很少；训练时用保守更新（偏行为策略），评估时 ε=0 贪心。
- 对照仍报一条**固定上年冠军**（不学习），避免 Q 学习只是把冠军换皮。

不做：行为克隆当主模型（那会回到「学持仓」）、个股排序、连续权重、在线探索。

**v1 实现说明**：第一期采用标准 Fitted Q-iteration（无额外保守正则）；状态特征为收益摘要窗口（近 N 日基准与专家超额），不含 MA200 开关位——MA200 门控状态延后到后续版本。

## 走步

交易年 Y：

- 训练只用测试年 < Y 的自然年轨迹。
- 可选动作 K 条只按 < Y 的年成绩排。
- 评估在 Y 年贪心选动作；不得读 Y 年夏普或 Y 年持仓当训练信号。
- 重放对照：Y-1 年夏普最高的 1 条（或前 K 等权合成，页面默认 **1 条冠军**，可改成 K 等权）。缺格子则该年不评分。

2018 不评分。默认从 2020 或 2021 起评。

## 页面

路径：`/backtests/offline-rl`  
侧栏：回测中心 → **离线策略学习**

1. 显示可用自然年轨迹、被排除的长窗、当年动作表（K 个指纹）。
2. 设 K、状态窗口（默认 20 日）、奖励说明（日超额，只读）。
3. 点「运行实验」才学；不自动开跑；与普通回测互斥同计划页。
4. 按年表：重放 vs Q 策略的夏普、超额、该年选了哪些专家。判定：各评分年简单平均夏普更高且平均超额不更差。

产物写入结果档案，配置标明本方法，避免再进入专家池。

## 不做（第一期）

- 不改回测中心，不接「开始回测」。
- 不用未来收益训练个股模型，不用 LightGBM 排序当本页主模型。
- 不在候选池里学连续权重或全市场稀疏动作。
- 不上 PPO / SAC / IQL / Decision Transformer。
- 写完参数不自动开始任何回测。

## 之后可以加（打赢重放之后）

在同一套走步和奖励下，把动作从「选专家」扩成「池内 Top N 权重」，再上保守离线 actor-critic。第一期不包含。

## 风险

专家高度同质时，Q 学习可能学成「几乎总选上年冠军」，样本外等于重放。页面要列出每日所选专家，若与冠军一致超过九成，判定里注明「未产生不同于重放的策略」。
