# 规则策略仓库（Wiki 多指标趋势跟踪）设计

日期：2026-09-06
来源：[MA、MACD、RSI等指标解析与量化策略实操](https://bigquant.com/wiki/doc/C54hzJxRqd)
状态：已确认

## 目标

在回测中心增加 **规则策略** 入口：一份 Python 只产出信号表（日期 / 股票 / 权重），平台负责调仓、空仓和止盈止损。第一份内置模板复刻 Wiki 文末的多指标趋势跟踪策略。

用户能在 QuantLab 里下载沪深300/中证500历史成分，用这篇策略跑回测，结果进入现有运行记录。

## 非目标

- 不做实盘。
- 不做策略 IDE / 粘贴任意 Python（这一期只内置模板 + 可改参数）。
- 不把机器学习训练和规则策略混成一条流水线。
- 不把现有槽位账户改掉；因子排序回测继续用槽位规则。
- 不把 KDJ 写进第一份模板（Wiki 示例没用 KDJ）。
- 不把成分股写入 `canonical.parquet`。

## 产品行为

### 数据中心

- 可下载并登记 Tushare `index_weight`（文档 [doc_id=96](https://tushare.pro/document/2?doc_id=96)）。
- 至少覆盖 `000300.SH`（沪深300）和 `000905.SH`（中证500）。
- 数据是 **月度**。每个交易日用「不晚于当日的最近一期」成分，禁止用未来月份。
- 缺成分股时，规则策略回测必须失败，中文原因写明要先下载，不得改成全 A。

### 回测中心

- 信号来源增加「规则策略」，与树模型 / 单因子排名并列。
- 选中后隐藏训练超参；展示策略名称、只读说明、可改参数。
- 第一份策略：**Wiki 多指标趋势跟踪**。
- 提交后创建普通 `backtest_runs`，冻结策略 id、代码哈希、参数、数据版本。

### 运行记录

- 沿用资金曲线、成交、指标。
- 额外展示：市场多头天数、信号条数、完全空仓天数。
- 配置快照能看出这是规则策略，而不是 LightGBM。

## 信号口径（第一份模板）

权威是 Wiki 文末示例，不是 Cowork 里后来改过的 0.45 阈值。

| 项 | 口径 |
|---|---|
| 股票池 | 当日沪深300或中证500成分 |
| 市场择时 | 仅沪深300成分：20 日收盘上涨占比 ≥ 50%，且 60 日上涨占比 ≥ 35%；否则该日无建仓信号 |
| 个股过滤 | 非 ST、非停牌、上市超过 365 个自然日、日成交额 > 5000 万元、板块相当于 BigQuant `list_sector IN (1,2,3)`（主板/中小板/创业板，排除科创板与北交所） |
| 四条件 | EMA20 > EMA60；MACD DIF > DEA 且柱 > 0；RSI(14) 在 40–72；收盘 > 布林中轨 |
| 指标价格 | 后复权收盘 `hfq_close` |
| EMA | 标准 EMA，α = 2/(N+1) |
| MACD | DIF = EMA12 − EMA26，DEA = EMA9(DIF)，柱 = 2×(DIF−DEA)。过滤只看柱的正负，排名用柱的截面分位 |
| RSI | 14 日；平均涨跌用 Wilder / 与常见 TA 一致的平滑 |
| 布林中轨 | 20 日 SMA |
| 20 日动量 | `hfq_close / hfq_close.shift(20) - 1` |
| 打分 | 截面分位：MACD 柱 40% + 20 日动量 35% + RSI 25% |
| 入选 | 四条件全过的股票里取 Top N（默认 10） |

成交额：语义是 **5000 万元人民币**。canonical `amount` 若沿用 Tushare 千元，先换成元再比。单位判断写进日志，禁止静默用错数量级。

月度成分 vs BigQuant 日频 `is_hs300`：这是已知近似，运行记录里写明「成分 as-of 月度」。

## 账户口径

仅 `kind=rule_signal` 使用，不改变因子排序回测。

- 调仓日：用当日信号做目标组合。
- 每只目标仓位 **10%**（相对调仓时权益）。最多 10 只；不够 10 只留现金。
- 调出或空仓：信号日 **收盘** 卖。
- 新买入：下一交易日 **开盘** 买。
- 仍在下期名单里的股票不换手，持有天数接着算。
- 未到调仓日不补仓。
- 止损 −10%、止盈 +25%：相对买入价，用当日 `hfq_high` / `hfq_low`；同一天两档都碰到则按 **止损**。
- 最长 45 个交易日，到期日收盘卖。
- 手续费默认买 0.03%、卖 0.13%、最低 5 元（页面可改）。
- 涨跌停、停牌不成交规则与现有回测一致。
- 本策略 **不用** 沪深300站上 MA200 开仓开关；择时就是成分多头比例。

非多头的调仓日：目标组合为空，持仓当日收盘清掉。

## 失败与空仓

- 没有 `index_weight`：`failed`，中文说明缺沪深300/中证500成分。
- 策略计算抛错：`failed`，保留日志。
- 区间内零信号：`completed`，0 笔成交，权益保持本金减费后的现金，不崩溃。
- 缺 `hfq_*` 或停牌/涨跌停列：该条规则跳过并写明，不静默当 True。

## 验收

1. 数据中心能看到指数成分和权重，能下载 300/500 的历史月度文件。
2. 回测中心能选规则策略、改阈值/TopN/调仓/止盈止损/最长持有，提交后配置冻结。
3. 合成数据单测覆盖：月度 as-of 成分、多头比例开关、四条件、Top10 打分、10% 仓位留现金、空仓日清仓、止损优先于止盈、45 日到期。
4. 浏览器：规则策略表单可见；因子排序表单仍在；缺成分时失败文案可读。
5. 现有槽位 / LightGBM 回测测试保持通过。
