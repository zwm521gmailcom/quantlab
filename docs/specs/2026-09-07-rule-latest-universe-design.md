# 规则策略：当时月度成分 + 次日开盘成交

日期：2026-09-07  
状态：已确认  
取代：

- 本稿此前「最新成分冻结、不随指数调仓」口径
- `docs/specs/2026-09-07-rule-strategy-page-design.md` 中可改参数 `up_pct_20` / `up_pct_60`

页面入口、路由 `/backtests/rules`、结果仍进 `backtest_runs`，不变。

## 目标

Wiki 多指标趋势跟踪改为：

1. 股票池用已下载的 Tushare `index_weight` **当时快照**：每个交易日取该日及以前最近一期沪深300 ∪ 中证500，不使用未来月份的成分。
2. **不做市场择时**：不再用 20/60 日上涨占比决定空仓。
3. 信号日收盘选出名单，**下一交易日开盘** 卖出调出、买入调入。

个股四条件、打分 Top N、5 日调仓、止损 / 止盈 / 最长持有，仍然保留。

## 非目标

- 不新下 `index_member` 进出日；月度 `index_weight` 即为 Point-in-Time。
- 不把 Cowork 收益率当作验收门槛，也不为这些窗口调参。
- 不新做第二套策略、不自建 BigQuant 完整下单引擎。
- 不把成分写入 `canonical.parquet`。
- 不改因子排序 / 槽位账户。

## 股票池

从已有 Tushare `index_weight` 读取：

- 每个交易日：`000300.SH`、`000905.SH` 各自取 `trade_date <= 当日` 的最大一期 `con_code`，再求并集。
- 两个指数允许快照日期不同，各用各的最近一期。
- 成分随月度快照变化，不把 2026-08 的名单套到 2018 年。

缺任一指数文件、或回测开始日任一指数没有 `trade_date <= 开始日` 的快照：回测 `failed`，中文说明去数据中心下载或把开始日调到成分覆盖之后，不得改成全 A。

不新增 `index_member` / 进出日下载。

## 信号

`wiki_trend_follow.generate_signals`：

- 去掉 `up_pct_20` / `up_pct_60` 过滤；默认参数不再包含这两项。
- 每个交易日只在冻结股票池上做：非 ST、非停牌、上市超过 365 个自然日、日成交额 > 5000 万元、主板/中小/创业（排除科创板与北交所）。
- 四条件不变：EMA20 > EMA60；MACD DIF > DEA 且柱 > 0；RSI(14) 在 40–72；收盘 > 布林中轨。
- 打分不变：截面分位 MACD 柱 40% + 20 日动量 35% + RSI 25%；Top N（默认 10），权重各 10%。
- 某日池内无人过关：该日零行，合法，不失败。

指标仍用 `hfq_close`；MACD 柱 = 2×(DIF−DEA)；RSI Wilder；布林中轨 SMA20。

旧草稿里若仍带 `up_pct_*`：后端忽略，不参与选股。

## 账户

仅 `kind=rule_signal`。

- 信号日：从回测区间第一个交易日起每 `rebalance_every`（默认 5）个交易日一档，用**当日收盘**指标生成名单。
- 执行日：信号日的**下一交易日开盘**处理目标组合：先卖出不在名单里的持仓，再用卖出后的现金按 10% 目标买入新名单。仍在名单里的股票不换手，持有天数接着算。
- 未到执行日不补仓、不按新信号换股。信号落在区间最后一天、没有下一交易日：该信号不成交。
- 执行日目标为空：当日开盘清仓。
- 止损 −10%、止盈 +25%：相对买入价，用当日 `hfq_high` / `hfq_low`；同一天两档都碰到则止损。执行日先完成开盘换仓，再对 **仍持有** 的仓位做止盈止损，避免已调出的票再按盘中极值成交。
- 最长 45 个交易日：到期日 **收盘** 卖。
- 手续费默认买 0.03%、卖 0.13%、最低 5 元、印花税 0。
- 涨跌停、停牌不成交规则与现有回测一致。

## 失败与空仓

- 没有 300/500 成分文件：`failed`。
- 回测开始日没有当时成分快照：`failed`。
- 策略抛错：`failed`，保留日志。
- 区间内零信号：`completed`，0 笔成交，权益为现金，不崩溃。

## 测试

1. 当时成分：后期快照里的股票不能出现在早期交易日；早期快照里的股票可以。
2. 无择时：即使「当前沪深300」多数下跌，只要个股四条件过关，该日仍可有信号。
3. 信号次日开盘买卖：调出次日开盘卖、新买入次日开盘买；买价是执行日开盘，不是信号日开盘；留存名字不换手。
4. 执行日空目标：开盘清仓。信号在最后一天无下一交易日则不成交。
5. 止损仍优先于止盈；45 日到期仍收盘卖。
6. 页面：`/backtests/rules` 无 `up_pct`；说明含「当时」成分；`configValue()` 不含这两项。
7. 现有槽位 / LightGBM 测试保持通过。
