日期：2026-09-02
范围：当时的 `quantlab-platform` worktree
原型目录：当时的 Codex brainstorm 目录 `20260901`

## 核对原则

1. 侧边栏采用已批准的两级分组定稿（`WORKSPACE/SYSTEM`、数据中心/因子研究含子项），
   与扁平原型不同是有意偏离。
2. 原型中的静态演示数字（27 个因子、5 条回测、收益率等）不复制；无真实记录时保持诚实空态。
3. 因子库不恢复右侧“当前选择/详情”面板。

## 补做顺序（先做真实信息可支撑项）

### A：因子库与因子详情的“加入回测”入口

- 因子库行内增加“查看详情 / 加入回测”；顶部选中因子支持批量“加入回测中心”。
- 因子详情沿用现有“加入回测草稿”动作。
- 复用 `/api/backtest-drafts`，跳转 `/backtests/new?draft_id=`；当前工作台已支持载入草稿。

A 状态（完成）：因子库新增“加入回测中心”批量入口与每行“加入回测”；复用
`/api/backtest-drafts` 并跳转工作台草稿。

### B：运行记录补可追溯结构

- 将可追溯性检查拆成真实 DAG/版本/Artifact 清单：
  数据版本指纹、因子版本、DAG 步骤、Artifact 哈希；
- 增加运行目录展示（从 Artifact 派生，不凭空列出文件）；
- 增加“复制规则”说明；
- 配置仍展示完整 JSON，同时用表格给出关键配置快照。

B 状态（完成）：新增配置快照、可追溯性检查、运行目录、复制规则区域；检查项全部
从不可变配置/DAG/Artifact 派生，不凭空列文件。

### C：研究总览健康度与最近回测骨架

- 数据健康度使用 `/api/datasets` 与质量告警的真实摘要，不做百分比假数据；
- “最近回测表现”区域在无记录时保留标题与诚实空态；
- 最近运行扩展为可读行（名称、类型、状态、时间）。

C 状态（完成）：首页增加“最近回测表现”与“数据健康度”区域；无记录时显示诚实提示，
有回测运行时不重复制造第二个可点击入口。

### D：手动/自动因子按原型分组重排

- 先按定稿保留现有字段与 API，把表单按原型分区为卡片；
- 结构字段先补齐可被当前登记模型支撑的部分；输出单位、复权方式等暂未建模的字段标记为后续数据模型扩展，不虚设输入。

D 状态（完成，第一版结构对齐）：
- 手动建立因子按“基本信息 / 公式与数据 / 计算口径 / 点时约束”分组卡片重排；
- 自动挖掘因子按“搜索范围 / 时间切分 / 表达式搜索约束 / 评价目标 / 运行规模”步骤分组；
- 未建模的字段（输出单位、复权方式、最大相关性等）不提供伪输入，以真实说明标注为后续数据模型扩展。

### E：数据中心质量摘要接口

- 需要新增轻量质量检查摘要 API（复用 parquet footer 与已登记 manifest）；
- 页面再按返回内容渲染检查清单。

E 状态（完成）：
- 新增 `GET /api/datasets/quality-summary`，只从已登记 manifest/footer 元数据派生检查项；
- 数据中心“数据集详情”新增“注册质量检查”清单，无绝对路径、不读取整张 Parquet。
