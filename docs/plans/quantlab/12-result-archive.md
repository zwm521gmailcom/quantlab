# QuantLab 结果档案实施计划

**目标：** 建立 `/backtests/runs` 回测结果清单，仅管理 BacktestRun；研究与模型训练分别在 `/research/runs`、`/models/runs` 管理。不保留右侧统计和查看方式卡片。

**依赖：** `11-backtest-workbench`。

## 清单设计

- 顶部仅展示结果保存总目录和筛选工具。
- `ID + 名称` 上下放在同一列；同列显示状态、创建时间、完成时间和耗时。
- 主要列：策略与因子、测试区间、累计/年化收益、夏普、最大回撤、胜率、基准、操作。
- 状态并入每条记录，不单设右侧统计块；未完成记录指标显示空值。
- 点击名称进入运行记录；复制配置进入回测工作台且不运行。
