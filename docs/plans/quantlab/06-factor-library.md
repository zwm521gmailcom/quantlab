# QuantLab 因子库实施计划

**目标：** 建立 `/factors` 作为版本化因子定义目录；本页不维护“当前回测组合”。

**依赖：** `04-factor-data`、`05-factor-research`。

## 目录列

- 名称与代码、版本、分类、方向、公式摘要、数据源、覆盖率、缺失行、状态、最后验证时间。
- 选中行只用于批量操作；详情通过独立 URL 打开。
- 筛选支持分类、来源、生命周期状态、质量状态和关键字。
