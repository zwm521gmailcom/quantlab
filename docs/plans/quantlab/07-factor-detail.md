# QuantLab 因子详情实施计划

**目标：** 建立 `/factors/{factor_id}/versions/{version_id}`，完整解释一个不可变因子版本及其真实诊断结果。

**依赖：** `06-factor-library`。

## 页面内容

- 定义：名称、代码、版本、分类、方向、公式 AST/可读公式、输入字段、观察窗口、缺失处理、作者和状态。
- 血缘：数据集版本、上游字段/因子、生成代码哈希、运行 ID 和 Artifact。
- 诊断：覆盖率、缺失、分布、分位数、每日 IC、分组收益、换手和稳定性；无运行时显示“尚未诊断”。
- 版本历史只读；“新建版本”复制定义到草稿，不修改历史版本，并完整继承原数据版本、窗口模式、缺失/异常规则、点时规则和代码哈希来源。
