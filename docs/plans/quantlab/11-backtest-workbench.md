# QuantLab 回测工作台实施计划

**目标：** 建立 `/backtests/new`，从 K 线、因子、模型、过滤、仓位和撮合模块组装可复现回测，并提交本地后台任务。

**依赖：** `10-strategy-center`。

## 可调配置

- 名称；中国 A 股 SH/SZ；数据/因子/模型版本；训练与测试区间。
- 训练过滤、测试过滤分别配置；估值和技术因子缺失策略分别配置。
- Top N、等权/分数权重、调仓间隔。
- 信号/执行语义独立：默认 t 收盘出信号、t+1 后复权开盘买入、t+2 后复权收盘卖出。
- 买入费率和最低费用、卖出费率和最低费用、滑点、初始资金、基准沪深300。
- 另存印花税、最低交易单位/手数、价格精度和 `unfilled_policy`（保持现金/下一可成交日/取消；默认保持现金），全部进入不可变配置快照。

## 实施任务

- [x] 写配置 Schema、跨字段验证、规范化和内容哈希测试。
- [x] 实现 K 线/因子/模型选择器，所有选择锁定版本。
- [x] 实现训练集与测试集过滤预览，返回逐阶段剩余数量。
- [x] 实现仓位、撮合和时间语义配置；避免“调仓两日”等同“持仓两日”。
- [x] 提交前执行同步门禁：版本状态、数据质量、样本量、时间边界、字段、模型规范、资金和费用全部通过后才创建 BacktestRun；门禁失败不创建记录、不排队。
- [x] 提交采用一次性 `submission_token` 幂等：同一 token 重复点击返回同一 Run；用户显式“重新运行”生成新 token 和新 Run ID，即使配置相同也保留新记录。
- [x] Job DAG 固定为数据快照校验 → 每窗口模型训练 → 预测 → 仓位生成 → 撮合 → 指标/Artifact；任一步失败，后续不执行并保留已有产物。
- [x] 页面显示校验问题、预估样本量和任务状态；复制配置不自动运行。

## 验证与审批

- [x] 使用小样本事件序列验证买卖日期、复权字段、买卖费率/最低费用/印花税、手数、滑点、停牌、涨跌停和未成交策略。
- [ ] 使用本地 `momentum_5` 2020 基线做回归测试，允许模型近似但配置与撮合必须精确。
- [ ] 浏览器验证所有用户指定参数可调、保存、刷新恢复和提交一次。
