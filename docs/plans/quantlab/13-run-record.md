# QuantLab 运行记录实施计划

**目标：** 建立 `/backtests/runs/{run_id}`，展示一次运行的完整配置、状态、绩效、曲线、交易、日志和输出文件。

**依赖：** `12-result-archive`。

## 页面内容

- 头部：名称、运行 ID、生命周期/质量状态、创建/开始/结束时间、耗时和结果目录。
- 主要指标：累计与年化收益、夏普、最大回撤、胜率、波动率、基准收益和超额收益。
- 图表：净值/基准/回撤；下方为年度、月度、交易、持仓、订单和日志。
- 完整配置快照：数据、因子、模型、过滤、仓位、时间语义、费用、基准、代码/环境指纹。
- 输出文件清单使用中文名称，保留原文件名、大小、哈希和下载。
- 状态、告警和失败原因放在明细中，不另建无关侧栏。
- 运行中页面每 5 秒轮询轻量状态端点；进入终态后停止。日志和大表由用户手动刷新/分页，不使用无界实时流。

## 实施任务

- [ ] 写运行聚合、部分结果、失败运行和 Artifact 权限测试。
- [ ] 实现运行详情/绩效/时序/交易/日志分页 API。
- [ ] 实现页面和图表；大表分页，大曲线下采样。
- [ ] 实现“复制并重新运行”：复制到回测中心草稿，绝不自动提交。

## 验证与审批

- [ ] 用至少完成、运行中、失败三类记录验收。
- [ ] 净值末值、收益、回撤、交易费用均可从明细复算。
- [ ] 下载只能访问该运行登记 Artifact。
