# QuantLab 因子研究中心实施计划

**目标：** 建立 `/research/factors`，统一进入手动建立、自动挖掘、单因子诊断和研究运行记录。

**依赖：** `04-factor-data`。

## 业务设计

- 页面分为“手动建立因子”和“自动挖掘因子”两个明确入口。
- 研究运行独立于回测运行，使用 ResearchRun，保存数据版本、因子版本、样本范围、过滤器、标签和统计结果。
- 最近研究清单显示名称/ID、类型、状态、创建时间、耗时、数据版本、结果摘要；点击进入运行明细。
- 稳定详情 URL 为 `/research/runs/{run_id}`；诊断必须锁定正式 DatasetVersion、FactorVersion、标签 `t+1 open -> t+2 close`、`hfq_*` 价格、点时规则与过滤快照。

## 实施任务

- [ ] 写 ResearchRun 仓储、筛选、状态转换和重跑复制测试。
- [ ] 实现 `/api/research-runs` 清单/详情/复制配置接口和研究详情页面；复制不自动运行。
- [ ] 页面实现两类入口、最近研究、质量告警与搜索筛选。
- [ ] “新建单因子诊断”从因子库选择一个已发布版本，并显式锁定数据版本。
- [ ] 所有研究输出登记 Artifact，文件显示中文名称。

## 验证与审批

- [ ] 非法状态转换、缺失版本、重复运行 ID 均失败。
- [ ] 浏览器验证手动/自动入口、复制配置不运行、运行详情可追溯。
- [ ] 主代理核对研究中心与因子库、回测中心职责不重叠。
