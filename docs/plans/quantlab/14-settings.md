# QuantLab 设置页实施计划

**目标：** 建立 `/settings`，管理本地路径、资源限制、默认回测参数和只读数据扫描，不保存密钥明文。

**依赖：** `00-foundation`、`11-backtest-workbench`。

## 设置范围

- 权威数据根、校准根、运行结果根的受控显示与连通性测试。
- 默认股票范围、基准、资金、费用、滑点、Top N、调仓与执行时间语义。
- 单任务并发、内存/行数/导出上限、日志保留策略。
- 数据扫描为手动触发；不定时自动修改元数据。
- 覆盖优先级固定为：历史 Run 快照 > 已发布 StrategyVersion > BacktestDraft 显式值 > 当前设置默认值；设置变化仅供新草稿初始化，不回填现有草稿、策略或运行。

## 实施任务

- [x] 写 Settings Schema、路径白名单、默认值、持久化和上述四级覆盖优先级冲突测试。
- [x] 实现脱敏设置 API；敏感配置只显示是否已配置。
- [x] 实现设置表单、连接测试、目录扫描和恢复默认值。
- [x] 修改设置不改变历史运行配置，也不自动运行任务。

## 验证与审批

- [x] 任意路径、符号链接逃逸和非本地监听默认被拒绝。
- [x] 浏览器验证保存/刷新、无密钥泄露、历史运行不变。
